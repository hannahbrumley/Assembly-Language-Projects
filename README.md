# Assembly-Language-Projects

A small collection of assembly-language coursework and practice exercises. Each file (.s) is a standalone class problem, homework, or solution demonstrating low-level programming concepts.

What’s included
- Multiple .s source files (prefixes like CP*, HA*, ICLA*) containing exercises and solutions.
- Inline comments in each file describing the task and approach.

How to view / run
- Open any .s file to read the code and comments.
- Toolchain/architecture details are noted at the top of each file — use the appropriate assembler/emulator (e.g., GNU as, NASM, or the target simulator) to assemble and run.

Skills demonstrated
- Translating algorithms to assembly
- Register and stack management
- Low-level debugging and problem decomposition
